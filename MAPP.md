# Minute MAPP 2026

## Create a 60-Second Video Mapping Artwork

As part of MAPP_MTL – Minute MAPP 2026, you will design and produce an original 60-second video mapping artwork created specifically for the festival's official projection surface.

Festival information: [MAPP_MTL – Minute MAPP 2026](https://www.mappmtl.com/en/evenement/mapp-x-i-minute-mapp-2026-i-1-oct-2026)

[Festival open call](https://derivative.ca/event/open-call-minute-mapp-mapp-mtl-festival-2026/75092)

## Project Objective

Create a compelling 60-second projection mapping animation using the official projection template. All visual techniques and media are welcome, provided the work is original and designed for the mapping surface.

## Team Formation

Work in teams of +/-4 students. Each member must take one of the following roles:

- **Project Manager** — planning, coordination, scheduling, and final submission.
- **Art Director** — visual concept, creative direction, and overall artistic coherence.
- **Typographer** — typography, titles, and graphic text integration.
- **Technical Director** — animation, compositing, rendering, and technical delivery.

## Project Process

- Form your team.
- Register for the festival before August 30, 2026.
- Download the official projection template.
- Develop your concept and create a storyboard.
- Produce your animation in Adobe After Effects using the official template.
- Integrate an original or royalty-free soundtrack.
- Include the title of the artwork, the artist or collective name, and all required credits.
- Respect copyright laws for any images, videos, or audio that you use.
- Export the final version without the After Effects mapping masks.

## Accepted Media

You are free to choose any creative approach, including:

- Motion graphics
- Live-action video
- Generative or procedural animation
- Digital collage
- Stop motion
- 2D or 3D animation
- Mixed media

The final piece should be visually engaging and adapted to architectural projection.

## Technical Specifications

| Item | Specification |
| --- | --- |
| Resolution | 3136 × 672 px |
| Duration | 60 seconds maximum |

| Format | `.mp4` |
| Maximum file size | 300 MB |
| Export software | Adobe Media Encoder |

## File Naming Convention

Name your file exactly as follows:

Example: `MadameX -- StudioCollective.mp4`
